# بک‌اند واقعی ایشِته

این یک سرور واقعی Node.js/Express است — نه نمونه‌ی نمایشی. با اجرای آن، ثبت‌نام،
ورود، ذخیره‌ی پروژه‌ها، و پرداخت واقعاً کار می‌کنند.

## راه‌اندازی (۳ دقیقه)

```bash
npm install
cp .env.example .env
# فایل .env را باز کنید و JWT_SECRET و ZARINPAL_MERCHANT_ID را با مقادیر واقعی خودتان پر کنید
npm start
```

سرور روی `http://localhost:3000` بالا می‌آید.

## چک کردن سلامت سرور
```
GET http://localhost:3000/api/health
```

## مسیرهای API

| متد | آدرس | توضیح |
|---|---|---|
| POST | /api/auth/signup | ثبت‌نام با نام، شماره موبایل، رمز عبور |
| POST | /api/auth/login | ورود و دریافت توکن |
| GET | /api/auth/me | پروفایل کاربر لاگین‌شده (نیاز به هدر Authorization) |
| GET | /api/projects | لیست برنامک‌های کاربر |
| POST | /api/projects | ساخت برنامک جدید (محدود بر اساس پلن) |
| PUT | /api/projects/:id | ویرایش برنامک |
| DELETE | /api/projects/:id | حذف برنامک |
| POST | /api/payment/request | شروع پرداخت واقعی زرین‌پال |
| GET | /api/payment/verify | تایید خودکار پرداخت (کال‌بک زرین‌پال) |

## قبل از رفتن به حالت واقعی (Production) حتماً:
1. یک حساب پذیرنده‌ی واقعی در zarinpal.com بسازید و `ZARINPAL_MERCHANT_ID` را با کد واقعی جایگزین کنید.
2. `ZARINPAL_SANDBOX=false` را در .env تنظیم کنید (فقط وقتی مطمئن هستید).
3. این سرور را روی یک هاست واقعی (مثل Liara، Ubuntu VPS، یا Railway) با HTTPS اجرا کنید — نه از روی سیستم شخصی.
4. `JWT_SECRET` را با یک رشته‌ی تصادفی و طولانی (حداقل ۳۲ کاراکتر) عوض کنید.
5. از دیتابیس SQLite برای شروع استفاده کنید؛ برای مقیاس بالاتر به PostgreSQL مهاجرت کنید.

## این کدها واقعاً چه‌کاری می‌کنند
- رمز عبور با bcrypt هش می‌شود (هرگز متن‌خام ذخیره نمی‌شود)
- ورود با JSON Web Token (JWT) به مدت ۳۰ روز معتبر است
- محدودیت تعداد برنامک بر اساس پلن کاربر (رایگان=۱، حرفه‌ای=۳، سازمانی=نامحدود) در سرور اعمال می‌شود، نه فقط در ظاهر
- پرداخت از طریق API رسمی زرین‌پال (نسخه‌ی ۴) درخواست و تایید می‌شود
